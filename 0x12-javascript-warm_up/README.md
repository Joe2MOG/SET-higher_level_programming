# 0x12. JavaScript - Warm up

## Description

This project covers the fundamentals of JavaScript run through Node.js:
variables (`let` and `const`), primitive data types, control flow with
`if/else`, loops (`for`), functions, arrays, and reading command-line
arguments through `process.argv`.

## Environment

- Node.js (tested with v14.x as required, developed on v24.x)
- Ubuntu 20.04 LTS
- Code style checked with semistandard

## Files

| File | Description |
| --- | --- |
| `0-javascript_is_amazing.js` | Prints a constant string |
| `1-multi_languages.js` | Prints three fixed lines |
| `2-arguments.js` | Prints a message based on argument count |
| `3-value_argument.js` | Prints the first argument, or a fallback |
| `4-concat.js` | Combines two arguments into one sentence |
| `5-to_integer.js` | Converts the first argument to an integer |
| `6-multi_languages_loop.js` | Prints an array of strings using a loop |
| `7-multi_c.js` | Prints "C is fun" a set number of times |
| `8-square.js` | Prints a square of X characters |

## Usage

Each file is executable. Run directly, for example:

\`\`\`
./0-javascript_is_amazing.js
\`\`\`
